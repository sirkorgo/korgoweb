**Windows Only "Just Works" Because They Have To**

People "choose" to use Windows because it's just easy to use and everything works out of the box. The only reason why every single game and app runs on Windows is because Microsoft paid millions so that every computer in the world would ship with Windows.\
That's why it seems like Windows is just the "jack of all trades", everything just runs on it. Developers aren't choosing to develop on Windows because they want to/like it, they kind of HAVE to, unless they only want around 5% of users who use Linux and Mac to use the app.

I'm not sure about other users, but my experience on Windows has been an actual hellscape. Having to troubleshoot driver issues all the damn time, having to mess with Windows registry settings, group policies, it's all just so tedious and annoying.

But, sure, Linux can tend to be just as confusing to have to maintain in the "spooky" command line. But I personally just find it SOO much easier, and straightforward, to just google or ask an LLM, "hey which command brings up the config for [something i need to configure". Usually, it's just a package installation, or one config file edit away, and 9 times out of 10, you get output that can help troubleshoot further. But for Windows, an "Unexpected error message" means you need to open 3 different admin utilities that probably haven't been updated since Vista, just to find out you were looking in the wrong place. Which brings me to my next point,

**Windows effectively hasn't been updated since 1996**
